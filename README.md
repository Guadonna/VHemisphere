# VHemisphere 0.1.0

Отдельная прошивка на основе Phazerville / Hemisphere для **O_C T4.1 rev3 с Teensy 4.1**. На этой плате используется Quadrants: четыре апплета и восемь CV-выходов. Поддерживаются штатные CV- и триггерные входы.

## Выходы

- Результат внутренней CV-обработки делится на 5: −5 В → −1 В, 0 → 0, +5 В → +1 В. Значения за пределами ограничиваются. Входы и алгоритмы не масштабируются.
- Преобразование выполняется после выходной аттенюации и slew. Внутреннее разрешение сохраняется до интерполяции по калибровочной таблице ЦАП.
- `GateOut` и `ClockOut`: 0/1 В, без аттенюации, slew и музыкального масштабирования. Если апплет формирует импульс обычным вызовом `Out`, это CV-сигнал: к нему применяются обычные выходные настройки.
- Квантайзер сохраняет музыкальные интервалы внутри алгоритма; на разъёме 1 В/октаву превращается в **0,2 В/октаву**, полутон — около 16,7 мВ.
- Диапазон фиксирован для всей этой прошивки. В меню I/O вместо вариантов строя указано `+/-1V /5`; autotune выходного строя отключён.
- Напряжения параметров в Voltage, AttenuateOffset, CVSeq, EnvSeq, OffsetQuant и EnsOscKey отображаются в новом масштабе. Это номинальные значения параметров до дополнительных обработок/уровня канала. В редакторе выходов Quadrants рядом со slew/level показано текущее **расчётное выходное напряжение** после обработки. Это не измерение вольтметром.
- Scope и пороги, относящиеся ко входам, сохраняют штатные единицы. Ноты, полутона и внутренние параметры апплетов сохраняют прежний смысл.

Настройки slew/level сохраняются в пресетах; на типизированные gate/clock они не влияют. Старые полноэкранные приложения исключены из сборки. Setup, редакторы шкал/форм волн и резервное копирование оставлены как служебные инструменты. Аудиоподсистема Quadrants сохранена; **этот диапазон относится только к восьми CV-выходам, не к отдельным аудиоразъёмам**.

## Калибровка

Откройте Setup/About → CALIBRATE. Для каждого выхода A–H мастер последовательно предлагает **−1, 0, +1 В**. Левый энкодер/навигация выбирает точку, правый меняет код ЦАП; переход вперёд — кнопкой правого энкодера. Измеряйте выбранный выход внешним вольтметром, остальные выходы в этом режиме устанавливаются в калиброванный ноль. Сохраните результат в конце мастера.

Используется прежняя структура аппаратной калибровки EEPROM; точки вне нового диапазона сохраняются. Входная калибровка не масштабируется: если она уже выполнена, не выбирайте сброс и пропустите её изменение. Во время ручной настройки код ЦАП управляется непосредственно, поэтому неправильная настройка может вывести напряжение за ±1 В. Калибруйте с отключёнными входами видеосинтезатора.

После инициализации ЦАП прошивка запрашивает калиброванный ноль. Поведение аналоговой схемы до инициализации, при сбросе и выключении питания не проверено и программным ограничителем не гарантируется.

Версия предназначена для стандартного O_C T4.1 rev3. Варианты с 20 Vpp или однополярным выходным трактом блокируются при запуске. Не используйте этот HEX для Teensy 3.2/4.0.

## Пресеты и установка

Используйте Teensy Loader и файл `VHemisphere-v0.1.0-Teensy41.hex` из Releases. Это самостоятельная сборка по адресу загрузки slot0, без меню multiboot и переходов в старые образы. До установки сохраните свои пресеты и калибровку средствами текущей прошивки.

VHemisphere хранит настройки в `VHEM.CFG`, резервную копию в `VHEM.BAK`, банки в `VHEM_000.DAT` и далее. Старые `GLOBALS.*` и `BANK_*.DAT` не загружаются автоматически и не удаляются сбросом VHemisphere. Формат банков совместим с исходной версией Phazerville, но импорт старых банков следует проверять отдельно: напряжения на выходах теперь другие. Автоматическая миграция и проверка каждого старого пресета не выполнялись.

## Сборка и проверки

```sh
git clone --recurse-submodules https://github.com/Guadonna/VHemisphere.git
cd VHemisphere
python3 -m venv .venv
. .venv/bin/activate
python -m pip install platformio==6.2.0
scripts/test-host.sh
pio run -d software -e VHemisphere -j 4
```

HEX находится в `software/.pio/build/VHemisphere/`. Зафиксированы платформа Teensy 5.2.0, framework и USBHost по коммитам, playback — через git submodule. CI выполняет host-тесты с UBSan и сборку Teensy 4.1.

v0.1.0 — **предварительный релиз для испытания на модуле**. Проверены сборка и программные тесты: границы/симметрия, несимметричные и обратные калибровочные таблицы, насыщение, разрешение, монотонность, реальный квантайзер, gate/clock и проход калибровки. Полная эмуляция экрана и периферии не выполнялась. Реальные напряжения, шум, тайминг на выводах и поведение питания требуют измерений на устройстве.
