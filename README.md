# VHemisphere 0.2.3

Отдельная прошивка на основе Phazerville / Hemisphere для **O_C с Teensy 4.0 и стандартной распиновкой O_C T4.0**: Hemisphere, два апплета и четыре CV-выхода. Формат панели 1U не определяет распиновку; для нестандартных плат необходимо сверить модель производителя. Поддерживаются штатные CV- и триггерные входы.

## Выходы

- Результат внутренней CV-обработки делится на 5: −5 В → −1 В, 0 → 0, +5 В → +1 В. Значения за пределами ограничиваются. Единицы входов и музыкальных параметров сохраняются. Общие пределы генерируемого CV заданы как ±5 внутренних вольт, соответствующие ±1 В на разъёмах.
- Преобразование выполняется после выходной аттенюации и slew. Внутреннее разрешение сохраняется до интерполяции по калибровочной таблице ЦАП.
- `GateOut` и `ClockOut`: 0/1 В, без аттенюации, slew и музыкального масштабирования. Если апплет формирует импульс обычным вызовом `Out`, это CV-сигнал: к нему применяются обычные выходные настройки.
- Квантайзер сохраняет музыкальные интервалы внутри алгоритма; на разъёме 1 В/октаву превращается в **0,2 В/октаву**, полутон — около 16,7 мВ.
- Диапазон фиксирован для всей этой прошивки. В меню I/O вместо вариантов строя указано `+/-1V /5`; autotune выходного строя отключён.
- Напряжения параметров в Voltage, AttenuateOffset, CVSeq, EnvSeq, OffsetQuant и EnsOscKey отображаются в новом масштабе. Это номинальные значения параметров до дополнительных обработок/уровня канала. Вклады параметров могут превышать ±1 В до суммирования и ограничения; например, CVSeq может показывать +1,06 В, но физический выход ограничен +1 В. В редакторе выходов Hemisphere рядом со slew/level показано текущее **расчётное выходное напряжение** после обработки. Это не измерение вольтметром.
- Scope и пороги, относящиеся ко входам, сохраняют штатные единицы. Ноты, полутона и внутренние параметры апплетов сохраняют прежний смысл.

Настройки slew/level сохраняются в пресетах; на типизированные gate/clock они не влияют. Старые полноэкранные приложения исключены из сборки. Setup, редакторы шкал/форм волн и резервное копирование оставлены как служебные инструменты.

## Исправления 0.2.2–0.2.3

- Voltage теперь позволяет выбрать от **−1,00 до +1,00 В**. Убран старый внутренний предел −3 В, который после деления на пять ограничивал отрицательный выход значением −0,6 В.
- Общие выходные пределы исправлены также для использующих их обработчиков и генераторов, включая CVSeq, EnvSeq, Calculate, Combin8 и VectorLFO. Генераторы, использующие полный диапазон, теперь рассчитывают его по ±5 внутренних вольт; уровни старых патчей стоит перепроверить.
- Показания Voltage, AttenOff, CVSeq, EnvSeq и редактора выходов округляются один раз до сотых: −0,6 В отображается как `-0.60V`, а не `-0.59V`.
- EnsOscKey показывает реальное номинальное значение своего кода выхода: 0,05…0,95 В. Входные показания Scope и пороги RunglBook сохраняют исходный масштаб.
- Сохранённый уровень Voltage −0,6 В остаётся −0,6 В после загрузки пресета. Чтобы получить −1 В, поверните ручку дальше в отрицательную сторону и сохраните пресет заново.

На основном экране Setup/About удержание кнопки правого энкодера возвращает в список приложений. Глобальная комбинация UP + правый энкодер также работает. В мастере калибровки правый энкодер по-прежнему переводит на следующую точку.

## Калибровка

Откройте Setup/About → CALIBRATE. Для каждого выхода A–D мастер последовательно предлагает **−1, 0, +1 В**. Левый энкодер/навигация выбирает точку, правый меняет код ЦАП; переход вперёд — кнопкой правого энкодера. Измеряйте выбранный выход внешним вольтметром, остальные выходы в этом режиме устанавливаются в калиброванный ноль. Сохраните результат в конце мастера.

Используется прежняя структура аппаратной калибровки EEPROM; точки вне нового диапазона сохраняются. Входная калибровка не масштабируется: если она уже выполнена, не выбирайте сброс и пропустите её изменение. Во время ручной настройки код ЦАП управляется непосредственно, поэтому неправильная настройка может вывести напряжение за ±1 В. Калибруйте с отключёнными входами видеосинтезатора.

После инициализации ЦАП прошивка запрашивает калиброванный ноль. Поведение аналоговой схемы до инициализации, при сбросе и выключении питания не проверено и программным ограничителем не гарантируется.

Версия предназначена для стандартного четырёхканального O_C T4.0. Используется исходная распиновка Phazerville T40 и его частота 300 МГц; это не разгон. Неверная цель процессора останавливает компиляцию.

## Пресеты и установка

Используйте Teensy Loader и файл `VHemisphere-v0.2.3-Teensy40.hex` из Releases. Это самостоятельная сборка со стандартной картой памяти Teensy 4.0. До установки сохраните свои пресеты и калибровку средствами текущей прошивки.

VHemisphere хранит настройки в `VHEM40.CFG`, резервную копию в `VHEM40.BAK`, пресеты Hemisphere в `VHEM40_PRESETS.DAT`. Старые `GLOBALS.*` и `HEM_PRESETS.DAT` не загружаются автоматически и не удаляются сбросом VHemisphere. Импорт старых пресетов Hemisphere следует проверять отдельно: напряжения на выходах теперь другие. Автоматическая миграция и проверка каждого старого пресета не выполнялись.

## Сборка и проверки

```sh
git clone --recurse-submodules https://github.com/Guadonna/VHemisphere.git
cd VHemisphere
python3 -m venv .venv
. .venv/bin/activate
python -m pip install platformio==6.2.0
scripts/test-host.sh
pio run -d software -e VHemisphere -j 4
```

HEX находится в `software/.pio/build/VHemisphere/`. Зафиксированы платформа Teensy 5.2.0, framework по коммиту. CI выполняет host-тесты с UBSan и сборку Teensy 4.0.

v0.2.3 — **предварительный релиз для испытания на модуле**. Проверены сборка и программные тесты: границы/симметрия, несимметричные и обратные калибровочные таблицы, насыщение, разрешение, монотонность, реальный квантайзер, gate/clock, полный проход ручки Voltage, надписи и пресеты Voltage, входы/смещения AttenOff и проход калибровки для четырёх каналов. Полная эмуляция экрана и периферии не выполнялась. Реальные напряжения, шум, тайминг на выводах и поведение питания требуют измерений на устройстве.
