# VHemisphere documentation

This documentation covers the Teensy 4.0 build with four CV outputs.
Start with [the project README](../README.md) for the output voltage conversion,
installation, calibration and verification limits.

Applet reference pages retain upstream descriptions of their algorithms.
Output CV examples must be divided by five and limited to +/-1 V;
input ranges and musical parameters are unchanged.

Pages use Jekyll permalinks when built as a documentation site. On GitHub,
open files in `_applets/` or `_apps/` directly if a permalink does not resolve.
